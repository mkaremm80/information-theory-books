information theory studies how much information a message carries and how efficiently it can be stored and sent. a source with predictable symbols has low entropy and can be compressed well. a source with random symbols has high entropy and cannot be compressed much. compression removes redundancy, and error correcting codes add redundancy in a controlled way so that a receiver can find and fix errors. security engineers use the same ideas to measure the strength of keys and the leakage of side channels. information theory studies how much information a message carries and how efficiently it can be stored and sent. a source with predictable symbols has low entropy and can be compressed well. a source with random symbols has high entropy and cannot be compressed much. compression removes redundancy, and error correcting codes add redundancy in a controlled way so that a receiver can find and fix errors. security engineers use the same ideas to measure the strength of keys and the leakage of side channels.
